# Content Checklist

This checklist captures the school-provided content needed to turn the current scaffold into a usable OSA thesis MVP.

## Core public content

- Official OSA office name, address, phone number, and email
- Office hours and appointment availability rules
- OSA announcement and advisory policy
- Student eligibility rules for protected actions
- Confirmed student email domain for OTP verification

## Service directory content

For each service page, prepare:

- Service title
- URL slug
- Short summary
- Who may avail
- Requirements
- Step-by-step process
- Processing time
- Fees, if any
- Office location or desk
- Related forms
- Approved source reference
- FAQ-ready questions and answers

Suggested MVP service entries already reflected in the scaffold:

- Student Orientation
- Scholarship Applications and Inquiries
- Accreditation of Student Organizations and Clubs
- Student Conduct and Discipline
- Student Manual Development and Review
- Issuance of Clearance and Good Moral Character Certificate

## Downloadable forms and manuals

Prepare approved digital copies and citation details for:

- EAC-C Student Manual PDF
- EAC-C Social Media Policy PDF
- EAC-C Scholarship Application
- EAC-C Incident Report
- EAC-C Academic Leave of Absence Application Form

For each file, capture:

- Display title
- File type
- Source office or owner
- Approval date or version
- Storage path or upload destination
- Short description for public listing

## Chatbot knowledge sources

Tier 1 FAQ data:

- Approved question
- Approved answer
- Service association, if any
- Source reference
- Publish status

Tier 2 document data:

- Document title
- Source reference
- Topic tags
- Section headings
- Chunk-ready extracted text
- Access rules for public use

Tier 3 escalation rules:

- Sensitive topics that must skip direct answering
- Cases that require staff review
- Cases that require appointment booking
- Standard escalation messages
- Turnaround expectations

## Appointment flow content

- Allowed request reasons
- Required student details
- Preferred scheduling format
- Available schedule windows
- Approval or confirmation policy
- Reschedule and cancellation rules

## Lost and found content

- Allowed item categories
- Claim proof requirements
- Claim verification steps
- Expiration or disposal rules
- Staff posting guidelines

## Admin and operations content

- Initial admin account list
- Role definitions
- FAQ approval workflow
- Document approval workflow
- Ticket escalation workflow
- Lost and found moderation rules

## Recommended encoding order

1. Public office details and service directory content
2. Forms and manuals metadata
3. FAQ entries for the most common concerns
4. Appointment and escalation rules
5. Lost and found rules
6. Admin user setup and approval workflows
